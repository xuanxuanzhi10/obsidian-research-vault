# 动作表示方法对比

## 核心矛盾

动作既要适配大模型接口，又要保持连续几何、时间一致性和跨机器人可迁移性。没有一种表示同时免费满足全部目标。

| 表示 | 模型输出 | 优点 | 代价 | 代表 |
|---|---|---|---|---|
| 逐维离散 token | action bins | 复用 LLM 自回归接口 | 量化误差、序列长 | [[OpenVLA]] |
| 频率压缩 token | DCT 系数序列 | 利用时间平滑性压缩 | 仍需离散解码 | [[FAST Tokenizer]] |
| 连续 Flow Matching | action chunk | 保留连续多峰分布 | 需要迭代生成 | [[π₀]]、[[Hy-Embodied-0.5-VLA]] |
| Relative EEF delta | 末端相对位姿 | 较易跨 embodiment | 依赖 IK 与可达性处理 | [[Relative EEF Action]] |

## 两个正交问题

“用关节还是 EEF 坐标”回答动作的物理语义；“离散 token 还是连续生成”回答模型怎样参数化分布。两者不要混成同一个维度。
