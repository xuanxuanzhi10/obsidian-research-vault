# 训练范式地图

## Pre-training

目标：从大规模、多任务数据获得通用 perception/action prior。

- [[Hy-Embodied-0.5-VLA]]：Hy-UMI-10K，Flow Matching
- [[π₀]]：Internet/VLM prior + 跨 embodiment robot data
- [[π₀.5]]：280k steps，把 robot、vision-language 与高层语义任务统一为 FAST/text next-token prediction（`α=0`）
- [[OpenVLA]]：从 Prismatic-7B 出发，用 970k OpenX robot trajectories 端到端训练 27 epochs；动作逐维分箱，CE 只监督 action token positions

## Supervised Fine-tuning

目标：用少量目标任务 demonstrations 对齐具体任务和 embodiment。

需要追问：全量更新还是 [[LoRA]]？SFT 是否损害预训练能力？目标任务数据是否覆盖失败边界？

## Post-training

- **π₀.5 hybrid post-training**：80k steps，新初始化 300M Action Expert，联合 `L_CE + 10·L_flow`；推理使用文本子任务 + 连续 Flow action。
- **OpenVLA downstream adaptation**：10-150 demonstrations；full FT 适合充足算力，LoRA r=32 在所测较小 variant 上以 1.4% trainable parameters 接近 full FT。

- **Positive-only**：SFT、DAgger correction aggregation
- **Reward/value-based**：依赖 reward、value 或 advantage estimation
- **Preference-based**：[[FlowPRO]] 使用 winning/losing action pairs + proximal regularization

## 核心比较维度

- 是否使用失败轨迹
- 是否需要 reward/critic model
- 是否需要在线交互
- 人工干预成本
- 是否容易 catastrophic forgetting

## 不要把阶段名当成机制

“pre-training / post-training”只说明相对顺序，不说明具体 loss。阅读时必须继续问：训练数据是什么、谁提供监督、哪些参数更新、是否需要在线交互。
