# 触觉标点

> [!abstract] 一句话定义
> 用接触开始、释放、滑移或就位等突变作为长任务的“标点符号”，切分示范并决定何时切换子任务。

![[n0-twam-teaching-punctuation.svg]]

```python
events = detect_change(tactile_stream)
events = fallback_to_gripper_aperture(events)
clips = segment(demonstration, events)
for clip in clips:
    clip.prompt = short_subtask_label(clip)
```

它比固定时间切段更贴近任务物理阶段，也能区分“夹爪闭合但没夹到”和“真正建立载荷”。风险是阈值、传感器噪声和弱接触会造成错误边界；N0-TWAM 仍使用夹爪开度后备和人工检查，推理时也依赖外部 scheduler。
