# 预测触觉与观测触觉

> [!abstract] 一句话定义
> 预测触觉回答“如果这样行动，接下来会摸到什么”；观测触觉回答“这一刻实际摸到了什么”。前者用于前瞻，后者用于纠错，不能互相替代。

![[n0-twam-teaching-two-paths.svg]]

## 因果差异

```python
future_touch = world_model(history, candidate_context) # 模型信念，可能错
action_plan = policy(predicted_video, future_touch)     # 接触前避错

actual_touch = sensor.read()                            # 真实反馈，有延迟
action_plan = correct(action_plan, actual_touch)        # 接触后恢复
```

[[N0-VTLA]] 是“只保留紧凑预测路径”的代表：当前差分 g 只能经 Predictor 变成未来 H=50 步净触觉变化 z，再进入 Action Expert；它没有当前触觉直达动作的 reactive port。[[N0-TWAM]] 则让预测分支生成 VAE latent residual，让观测分支读取三轴 force map；两者使用不同表示，是因为“生成”和“条件输入”的任务不同。T-Rex 主要属于观测/反应路径；FTP-1 也主要消费当前触觉。

```text
当前观测 O：sensor_t → policy             优点：真实、能纠偏；缺点：接触后才知道
紧凑预测 P：sensor_t + context → z_future 优点：小接口、能前瞻；缺点：可能预测错
生成预测 P+：history → future tactile      优点：信息完整；缺点：模型和训练更重
组合 O+P：预测负责避错，观测负责校正     最完整，但必须证明额外复杂度值得
```

## 评价时必须分别消融

- current-only / predicted-only / both / neither；
- 接触前错误率与接触后恢复率；
- 预测 horizon、传感器延迟、模型误差；
- 视觉可辨任务与视觉歧义任务。
