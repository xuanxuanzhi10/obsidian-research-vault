# 预测触觉与观测触觉

> [!abstract] 一句话定义
> 预测触觉回答“如果这样行动，接下来会摸到什么”；观测触觉回答“这一刻实际摸到了什么”。前者用于前瞻，后者用于纠错，不能互相替代。

![[n0-twam-teaching-two-paths.svg]]

## 因果差异

```python
future_touch = world_model(history, candidate_context) # 模型信念，可能错
action_plan = policy(predicted_video, future_touch)     # 接触前避错

actual_touch = sensor.read()                            # 真实反馈，有延迟
action_plan = correct(action_plan, actual_touch)        # 接触后恢复
```

N0-TWAM 让预测分支生成 VAE latent residual，让观测分支读取三轴 force map；两者使用不同表示，是因为“生成”和“条件输入”的任务不同。T-Rex 主要属于观测/反应路径；FTP-1 也主要消费当前触觉，并明确把未来触觉预测列为未来方向。

## 评价时必须分别消融

- current-only / predicted-only / both / neither；
- 接触前错误率与接触后恢复率；
- 预测 horizon、传感器延迟、模型误差；
- 视觉可辨任务与视觉歧义任务。
