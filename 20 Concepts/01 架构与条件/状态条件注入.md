# 状态条件注入：Token 路径与调制路径

相关：[[Adaptive RMSNorm]] · [[Block-wise Causal Attention]] · [[Action Expert]] · 深入对比：[[状态条件注入方式比较]]

> [!abstract] 一句话定义
> Robot state 可以作为 attention token，也可以调制每层 normalization；关键差异不是“有没有输入 state”，而是 state 通过什么计算路径影响所有 action tokens。

## 第一层：先区分两条路径

```text
Token 路径：state → projection/token → Attention → action 查询它
调制路径：state → condition MLP → 每层 scale/shift/gate → 改变全部 action hidden
```

token 像会议中的一个参会者，需要 action query 主动读取；adaptive norm 像控制面板，直接改变每层通道。类比的边界是：token 也能形成全局作用，调制也不自动包含空间或对象级推理。

## 第二层：最小机制例子

假设 `state=[joint_1,joint_2,gripper]`，两个 action tokens：

```python
def token_conditioning(state, action_tokens):
    s = linear(state)[None, :]                 # [1,d]
    sequence = concat([s, action_tokens])      # [1+H,d]
    return attention(sequence)[1:]             # action 通过 attention 读取 s

def adaptive_conditioning(state, action_tokens):
    scale, shift, gate = mlp(state).chunk(3)   # 各 [d]
    h = rms_norm(action_tokens)                # [H,d]
    return action_tokens + gate * block((1+scale)*h + shift)
```

允许路径：π₀ 的 A query 读取 S block；禁止路径：S 不能读取随 flow timestep 变化的 A，否则 state KV 无法缓存。Adaptive 路径则必须明确检查 condition MLP 到底接了 state、timestep，还是两者。

## 第三层：不同论文怎样做

| 模型 | state 路径 | timestep 路径 | 核实状态 |
|---|---|---|---|
| [[π₀]] | continuous state 线性投影成单独 S block，走 Action Expert | sinusoidal τ 拼入 noisy-action embedding MLP | PDF Appendix B 已核对 |
| [[π₀.5]] | state 离散化进入 tokenized prompt | timestep 专用 MLP 后以 AdaRMSNorm 注入每层 Action Expert | PDF Appendix E + 官方 OpenPI 代码 |
| [[Hy-Embodied-0.5-VLA]] | projected state 为独立 block | 论文未报告 AdaRMS/AdaLN | 全文已核对 |
| [[FTP-1]] | proprioception + timestep 共同经 condition path | Adaptive RMSNorm scale/shift/gate | Appendix B.3 与代码已核对 |

同一个模型可以同时用 token 与调制，但“用了 AdaRMSNorm”不能推出“不再有 state token”，也不能推出 AdaRMSNorm 接收的一定是 proprioception。

## 第四层：如何选择与验证

- Token 优点：信息交互灵活、容易显式检查 attention；代价是模型必须学会读取它；
- Adaptive norm 优点：每层直达、不增加序列长度；代价是全局调制可能扰动预训练分布；
- 两者共存可能互补，也可能冗余，需同模型同预算消融；
- 必测：state dropout、状态噪声/延迟、跨 embodiment、关节极限附近、是否影响无状态或缺状态退化；
- 证据边界：FTP-1 声称 adaptive proprioception 更稳健，但没有完整独立数值表；π₀ 的论文也没有 token-vs-adaptive 的直接消融。
