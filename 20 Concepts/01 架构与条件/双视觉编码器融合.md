# 双视觉编码器融合：给同一 patch 两种视觉坐标

出现于：[[OpenVLA]] · 相关：[[Action Expert]]

> [!summary] 一句话定义
> 让两个预训练视觉 encoder 处理同一图像，在对应 patch 上沿 feature channel 拼接，再投影到语言模型 embedding space，以同时利用图文语义与局部视觉结构。

## 第一层：直觉入口

SigLIP 更像带语言标签的观察者，擅长“这是什么”；DINOv2 更像研究图像内部结构的观察者，补充局部形状和空间线索。两者对同一 patch 给出不同描述，再由 projector 合并。

类比边界：DINOv2 不直接输出 3D pose 或像素坐标，空间能力仍是隐式 feature，必须由下游控制 loss 学会利用。

## 第二层：tensor flow

```python
def fused_vision(image):                    # [B,3,H,W]
    sig = siglip(image)                     # [B,N,D_sig]
    dino = dinov2(image)                    # [B,N,D_dino]
    fused = concat([sig, dino], dim=-1)     # [B,N,D_sig+D_dino]
    return mlp_projector(fused)             # [B,N,D_llm]
```

允许路径：同一 patch 的两类 feature 在 channel 维合并。错误理解：在 token 轴拼接成 `[B,2N,D]`；OpenVLA 不是这种做法。

## 第四层：证据与边界

OpenVLA 的 Bridge-only 消融中，双 encoder 45.6±5.6%，SigLIP-only 40.6±5.5%；这支持约 5 点增益。但 OpenX 数据相对 Bridge-only 带来约 30 点，说明在这组实验中数据覆盖更重要。

成本包括多一个大型视觉 encoder、feature 对齐要求和更高显存。需要分别测试：语义 grounding、精细空间任务、高分辨率、冻结/微调策略，而不能从一个 aggregate success 推断所有视觉能力均提升。
