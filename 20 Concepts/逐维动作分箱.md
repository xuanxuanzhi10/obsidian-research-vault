# 逐维动作分箱：把连续控制改写为分类

出现于：[[OpenVLA]] · 对比：[[FAST Tokenizer]] · [[Flow Matching]]

> [!summary] 一句话定义
> 对动作向量的每个维度分别确定数值范围、均匀切成有限 bins，再让语言模型把 bin ID 当成 token 自回归预测。

## 第一层：为什么会有它？

LLM 的标准输出层给出 vocabulary 上的 categorical logits，而机器人需要浮点动作。逐维分箱像给每个旋钮刻 256 个档位：不改 LLM 架构，只需让它预测档位编号。

类比边界：真实动作维度有不同单位和分布，“第 128 档”只在指定维度与统计范围内有意义。

## 第二层：最小例子

假设平移维度训练分布的 1%/99% 分位数为 `[-0.04, 0.06] m`：

```python
def quantize(value, lo=-0.04, hi=0.06, bins=256):
    value = clip(value, lo, hi)
    index = floor((value - lo) / (hi - lo) * bins)
    return clip(index, 0, bins - 1)

bin_width = (0.06 - (-0.04)) / 256  # 约 0.39 mm，只对这个例子成立
```

[[OpenVLA]] 对 7D action 逐维做这一步，再把 7 个 bin 映射为 7 个 Llama vocabulary tokens。

### 独立量化不等于独立概率

```text
量化器：每维单独找 bin
概率模型：p(z1...z7|condition)=∏ p(zd|condition,z<d)
```

后一个 token 可以条件于此前 token，所以自回归模型仍能学习维度耦合和多峰 categorical distribution。真正损失的是连续分辨率与显式几何结构。

## 第三层：与相近方法比较

| 方法 | 建模单位 | 优点 | 主要代价 | 核实状态 |
|---|---|---|---|---|
| 逐维分箱 | 单步、单维 | 直接复用 LLM CE | token 多、量化误差、无时间压缩 | OpenVLA PDF 已核对 |
| [[FAST Tokenizer]] | 整段动作频率系数 | 压缩时间冗余 | tokenizer/码率更复杂 | π₀.5 已核对用途 |
| [[Flow Matching]] | 连续 `[H,D]` chunk | 连续、多峰、并行输出 chunk | 需专用 loss 与多次积分 | π₀/π₀.5 已核对 |

## 第四层：研究核查

- 范围应用 quantile 可以抗 outlier，但会 clip 尾部动作；
- bin 数越多不一定越好：分类更细、数据也更稀疏；
- 跨机器人必须重新明确 action 语义、单位、坐标系和 quantiles；
- 必测 quantization reconstruction error、每维饱和率、greedy vs sampling、控制频率和动作抖动；
- 不要写统一“毫米/格”，除非给出该维真实 `q01/q99`。
