# 触觉信号表示

> [!summary] 一句话定义
> 把力、力矩、皮肤形变和它们的时间变化，编码成 policy 能稳定消费的状态；关键不是“变成 token”本身，而是不要丢掉接触的时间、空间和瞬时尺度。

## 直觉理解

视觉像远距离地图，触觉像接触后的局部测量。一个“触觉向量”常常混合了三个不同问题：

- **发生了多大作用力？** 当前 6D wrench；
- **接触正在如何变化？** 一段 wrench history；
- **接触在哪里、形状怎样？** 稠密形变图或触觉图像。

## 为什么不能只用当前力？

相同的当前力可能来自完全不同的过程：稳定抓住、正在变紧、刚开始滑、撞击后回弹。时间窗口提供导数和模式信息。反过来，历史压缩会平滑掉突发冲击，因此 T-Rex 又保留当前力的直接投影。

## 最小实现

```python
class TactileTokenizer:
    def forward(self, wrench_hist, wrench_now, deform, finger_id):
        # wrench_hist: [batch, finger=10, time=16, channel=6]
        dynamic = self.temporal_conv(wrench_hist)
        dynamic = self.mean_pool(dynamic)          # [..., 256]
        dynamic = self.vq(dynamic, codebook_size=64)
        dynamic += self.finger_embedding(finger_id)

        instant = self.force_projection(wrench_now)
        geometry = self.frozen_deform_encoder(deform)
        return concat(dynamic, instant, geometry, dim="token")
```

训练 VQ-VAE 时应提高强接触帧权重，否则大量无接触帧会诱导 codebook collapse。跨手指共享时域卷积可减少参数，但必须给 finger identity，否则拇指和小指的几何角色会被抹平。

## 表示方法谱系

| 原始信号 | 常见表示 | 擅长 | 容易丢失 |
|---|---|---|---|
| 标量/阵列压力 | MLP、统计量 | 接触与压力大小 | 时序与几何 |
| 6D wrench | MLP、TCN、Transformer、VQ | 力/力矩动态 | 接触面内部结构 |
| 触觉图像/形变图 | CNN、ViT | 边缘、滑移、剪切、材质 | 全局受力与长历史 |
| 多模态触觉 | concat、cross-attention、专门 expert | 互补信息 | 校准、频率和同步复杂度 |

## 在 T-Rex 中怎样用

T-Rex 用最近 16 帧 6D wrench 的 VQ-VAE token、当前 wrench 投影和当前形变图特征拼成 tactile token，送入高频 Tactile Expert。详见 [[T-Rex]]。

## 优势与边界

优势是显式保留三种尺度；代价是需要同步、校准与专门预训练。T-Rex 的消融显示完整模型 65%，去触觉 42%，只保留部分触觉表示为 54–59%。这是该机器人与任务集上的证据，不证明 VQ-VAE 在所有传感器上都最优。

## 继续调研时追问

1. 原始硬件输出是 force、taxel、RGB、depth、event 还是 vibration？
2. 表示是否保留时间方向、接触位置和不确定性？
3. 是否对漂移、传感器磨损、跨指/跨硬件做归一化？
4. 表示是为状态估计、动作生成，还是二者共同训练？
