# π₀.5

上级地图：[[VLA 学习地图]] · 相关专题：[[数据策略对比]]

架构概念：[[Adaptive RMSNorm]] · [[状态条件注入方式比较]]

> [!summary] 一句话结论
> π₀.5 把问题从“会不会完成一个已训练技能”推进到“能否在没见过的家庭环境里，根据语言完成长时程任务”。

## 01 为什么只增加机器人数据不够？

机器人轨迹精确但昂贵，覆盖不了开放世界中的物体、语言和场景变化；互联网视觉语言数据覆盖广，却没有可执行动作。

→ 关键不只是数据量，而是怎样让不同监督形式互补。

## 02 核心答案：异构 co-training

把多种数据放进统一训练过程：robot trajectories 教“怎么动”，视觉语言数据教“世界里有什么”，语言与高层语义任务教“下一阶段做什么”。

因果链是：

```text
更广的语义覆盖
→ 更可靠地识别陌生环境与任务阶段
→ 生成与当前阶段一致的低层动作
→ 支撑未见家庭中的长时程任务
```

## 03 “层级推理”该怎样理解？

它不是两个完全独立、手工拼接的模型。更稳妥的理解是：训练中同时塑造高层语义/子任务能力和低层连续控制能力，使同一系统能在长任务中维持阶段性目标。

## 04 主动回答读者疑问

> [!question] 非机器人数据既然没有 action，为什么会帮助 policy？
> 它不直接教 motor command，而是减少感知、语义和任务分解上的盲区；动作能力仍需机器人数据落地。

> [!question] π₀.5 只是 π₀ 加更多数据吗？
> 不只是“更多”，而是更异构的训练任务与监督接口。研究问题从 dexterous control 转向 open-world generalization。

> [!question] π₀.5 用 AdaRMSNorm 后，还输入 state token 吗？
> 会输入 state，但要准确区分路径：官方 OpenPI 实现把 state 离散化并序列化到 tokenized prompt；AdaRMSNorm 注入的是 Flow Matching timestep，不是 state。相比之下，π0 使用 continuous state suffix token，但不使用 AdaRMSNorm。

## 05 证据边界

论文展示了在未见家庭中执行约 10–15 分钟长任务的能力。数据配比、阶段步数和类别统计在正式精读前不写成确定结论，见 [[待核实事实]]。
